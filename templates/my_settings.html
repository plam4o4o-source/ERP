{{ icon('globe') }} Автоматична синхронизация с GitHub

Създайте ново частно (private) хранилище в GitHub само за базата данни (Settings → New repository → Private), и генерирайте personal access token с права за запис (repo). Не използвайте публично хранилище — базата данни съдържа данни на ваши клиенти.

При включена синхронизация: базата се качва автоматично малко след всяка промяна (нов документ, клиент, служител); нова инсталация с попълнени данни тук автоматично изтегля последната запазена база при първо стартиране. Ако няма интернет, промените остават запазени локално и се качват веднага щом връзката се възстанови. ⚠ Предназначено за една активна инсталация наведнъж (или сървърен режим) — ако двама души работят едновременно на различни компютри без сървърен режим, по-късното качване може да презапише по-ранни промени.
